# emulator-screen

## Description

* `led_matrix_screen.h`:
  * Only used as emulator when programmer wants to develop further function for the InspireRV in Windows/MacOS 
  * Draw the screen presenting 8x8 LED matrix in InspireRV with 9 buttons and 64 LED matrix buttons
  * Color is hard-coded in the following, change the value in ```led_matrix_screen.h``` for different colors
